## 🚀 Sobre este proyecto

Este es mi portafolio personal donde presento mis proyectos, habilidades y formación académica como **Desarrollador Fullstack**.

Construido con tecnologías modernas para ofrecer una experiencia rápida, responsiva y visualmente atractiva.

## 🛠️ Tecnologías utilizadas

| Tecnología | Uso |
|---|---|
| **React** | Framework principal de UI |
| **Vite** | Bundler y entorno de desarrollo |
| **React Bootstrap** | Componentes y sistema de grilla |
| **CSS Vanilla** | Estilos personalizados y animaciones |
| **React Icons** | Iconografía |

## 📂 Estructura del proyecto
    
